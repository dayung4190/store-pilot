# Store Pilot

Store Pilot is an Inventory and Order Management System built with Python, Flask, and MongoDB.

The project provides a REST API for managing products, including creating, viewing, updating, and deleting product records.

## Features

- Create a product
- View all products
- View a single product
- Update a product
- Delete a product
- Validate product data
- Prevent duplicate SKUs
- Automated tests using pytest

## Technologies

- Python
- Flask
- MongoDB Atlas
- PyMongo
- python-dotenv
- pytest
- Git and GitHub
